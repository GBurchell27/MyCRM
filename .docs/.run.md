# How to run

1. Install Python from https://python.org (check "Add to PATH").
2. Optional (recording + AI summarize):

```bash
pip install -r requirements.txt
```

3. From this folder, run:

```bash
python main.py
```

A `crm_data.db` file is created next to `main.py` on first run — back that up.
Recordings land in `recordings/`. When screen video is on you get a single `.mp4` containing both the picture and the audio; with video off you get a `.wav` instead.

In the meeting editor, **Include screen video** (on by default) captures the primary monitor at ~8 fps alongside the mic. Use **Open recording ▾** to open any clip’s video or audio. You can stop and start again in the same note — each clip is kept; later AI summaries append under the first (`--- Recording 2 ---`, …). After each stop, transcription then AI Summarize run automatically (spinner shown); the window stays open until transcription succeeds. Manual **AI Summarize** rebuilds one combined summary from all clips. AI still summarizes from audio/transcript + notes (not the video frames).

**Include system audio** (on by default) also records whatever the speakers play — the other side of a call, or a video being shared — via the WASAPI loopback of the default playback device. It is mixed with the mic so Whisper transcribes both sides. This needs the `soundcard` package; without it the checkbox is disabled and only the mic is recorded. If the track comes out silent, check that the meeting is playing through the device set as **Default** in the Windows sound settings.

When both audio and video are captured, the audio is merged into the MP4 on stop (the video stream is copied, not re-encoded) and the intermediate `.wav` is removed. Transcription then extracts a small mono AAC track from the MP4 rather than uploading the whole video.

Video is written as H.264 using the ffmpeg binary that ships with `imageio-ffmpeg`, so it plays in Windows Media Player. Without that package it falls back to MPEG-4 Part 2, which only VLC-style players can open. To repair older recordings saved in the old format:

```bash
python video_transcoder.py
```

Set an OpenAI key via the **⚙ button** at the right of the tab bar (or `Ctrl+,`, or `OPENAI_API_KEY`) to enable Whisper transcription and AI Summarize in the meeting editor.

The same window holds the rest of the settings: the model and reasoning effort behind each AI job (summaries, catch-up briefs, new contact details, email drafting, transcription), how far back catch-ups look and how much of each meeting the AI is given, how far ahead recurring notes are created, and how a new meeting note starts out. Everything is stored in `crm_data.db`, so it survives upgrades.

Optional standalone `.exe`:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed main.py
```

The exe lands in `dist/`.
